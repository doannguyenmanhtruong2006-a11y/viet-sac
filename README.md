# VietSac – Website đặt lịch

## Giới thiệu
VietSac là website đặt lịch trực tuyến, giúp người dùng dễ dàng lựa chọn dịch vụ, chọn thời gian và đặt lịch nhanh chóng.

## Chức năng chính
- Đặt lịch online
- Xem và quản lý lịch hẹn
- Quản lý dịch vụ
- Giao diện thân thiện, dễ sử dụng

## Công nghệ sử dụng
- React
- TypeScript
- Vite
- HTML, CSS

Làm chủ yếu bằng chatgipiti
